## ✨ Features

- **Responsive** designs
- **Smooth animations** and hover effects
- **Ready-to-use** code snippets
- **Well-organized** folder structure

## 🎮 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/html-css-js-effects.git
   cd html-css-js-effects
   ```

2. **Open any demo**
   - Simply double-click any `index.html` file
   - Or use Live Server extension in VS Code
   - Or serve locally: `npx live-server`

3. **Customize**
   - Edit CSS variables for colors/themes
   - Modify animations timings
   - Add your content
